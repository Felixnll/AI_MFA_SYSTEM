IS ai in here?
Short answer: Yes — AI/ML is integrated.

Where: model and code live in the workspace: app.py, train_model.py, inspect_model.py, risk_model.joblib, training_data.csv, ml_predictions.jsonl, admin_ml_dashboard.html

How it's used: app.py loads risk_model.joblib and calls predict_risk_ml() during login; if ML confidence >= 0.60 the ML label is used, otherwise the code falls back to the rule-based simple_risk_engine().

Feature vector (order): failed_attempts, short_interval, unknown_device, unusual_hour, password_match.

Admin / observability: endpoints /ml_status, /ml_predict, /ml_samples and /admin/ml_dashboard show model status, run predictions, and display recent prediction events (logged to ml_predictions.jsonl).
---------------------------------------------------------------------------------------------------------------
Summary of the ml used:

Model: RandomForestClassifier (ensemble decision-tree classifier from scikit-learn).

Task / Output: Supervised multiclass classification into risk labels (low / medium / high).

Training: Synthetic labeled dataset generated by train_model.py, model persisted to risk_model.joblib.

Features (input order): failed_attempts, short_interval, unknown_device, unusual_hour, password_match.

Inference flow: predict_risk_ml() in app.py returns probabilities; if top probability ≥ 0.60 the ML label is used, otherwise the app falls back to the rule-based simple_risk_engine().

Techniques / tooling: feature engineering (binary + count features), supervised learning, model serialization with joblib, numpy/scikit-learn for training/inference; prediction events logged to ml_predictions.jsonl and feature rows to training_data.csv for future retraining.

Observability: feature importances inspected via inspect_model.py and surfaced by /ml_status, /ml_samples, /ml_predict, /admin/ml_dashboard.

Caveats / next steps: current model trained on synthetic data—recommend collecting labeled real events, perform cross-validation/calibration, add monitoring, and consider stronger models (XGBoost/LightGBM) or rebalancing if needed.
